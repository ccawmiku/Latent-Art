# 隐空间生成艺术画布

一个单文件、纯前端的生成艺术实验。画面由隐空间状态持续演化，经双隐藏层解码为条纹、块面和颜色参数，并提供可交互的隐空间地图与解码过程视图。

## 主要能力

- 横向、纵向和双向构图模式。
- 自动或手动选择颜色数量与调色板。
- 调节随机度，控制连续演化与跳变幅度。
- 在隐空间地图中点击跳转。
- 中英文界面、展览模式和 PNG 导出。
- 状态保存在浏览器本地。

## 使用

直接打开 “index.html” 即可。若浏览器限制本地资源，可运行：

~~~bash
python -m http.server 8000
~~~

然后访问 “http://127.0.0.1:8000”。

## 部署

项目不需要构建，可直接部署到 GitHub Pages 或任意静态托管服务。仓库中的 “.nojekyll” 用于避免 GitHub Pages 的 Jekyll 处理。
